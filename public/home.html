Export

Ship it as a spec, not a chat log

Every graph exports as one plain file your agents, CI and teammates can run. It lives in your repo, diffs cleanly, and nothing about it depends on us.

Try it in the studio 
# nodeheus.graph.yaml
auth-service:
  harness: claude-code
  model: claude-opus-5-5
  scope: services/auth/**
  needs: [spec, postgres]
  review: hermes

$ npx nodeheus run auth-service

Your whole architecture, every agent and every rule fits in one 6 kb file.

What is free, and what makes Pro?

The whole canvas is free, including every node type and all three harnesses. Free runs one agent at a time. Pro runs up to eight in parallel and adds option boards, the impact view and run history.

Which agents can I use?

Claude Code, OpenAI Codex and Nous Hermes today. Any agent that runs in a terminal can be added as a custom harness, with its own model, tools and permissions per node.

Where does my code go?

Agents run on your machine or in a sandbox you choose. nodeheus stores the graph and the run history. Your source code stays in your repository.

What is an option board?

Ask a node for three to six versions, built in parallel by different agents or models. Compare them side by side and pick one. The rest are archived, so you can come back to them.

Can my team work on the same graph?

Yes, on Team. Everyone sees the same graph, the same live agents and the same history. Review links let someone approve a change without opening the studio.

Do I need to install anything?

The canvas runs in your browser. A small CLI connects it to the agents on your machine: npx nodeheus connect.
